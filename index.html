01 / AI 秘书

别只拿 ChatGPT 问问题：把它变成你的 AI 秘书

我现在更常用 ChatGPT 的方式，不是“问一句、答一句”，而是让它知道我在做什么、读我的资料、调用外部工具、最后帮我把事情推进下去。

核心变化

普通 ChatGPT vs AI 秘书

每次重新交代背景 → 问问题 → 自己去执行
→
长期上下文 → 查真实资料 → 调工具 → 记任务 / 排日历 / 执行动作

我现在把它接到了哪些东西上？

任务和日历

读 TickTick、安排待办、看截止时间、写入 Google Calendar，再从一堆事情里挑今天真正该做的。

文件和项目

从 Google Drive 找资料、读 GitHub 仓库、接着以前的项目继续推进，不用每次手工复制背景。

公开数据获取

接上对应 MCP / API 后，可以把公众号文章与评论、抖音评论和视频字幕、小红书笔记/评论/博主公开数据等抓回来，再交给 AI 做整理、总结和分析。

自动处理信息

不是只“搜到”，而是继续做清洗、分类、提炼观点、找高频问题、生成表格或形成下一步行动。

一个很真实的例子

# 我只说一句
“明天下午我要给学弟做 AI 分享，4 点开始。
你先帮我记一下，再看看我之前做过什么分享，
告诉我今晚最应该先准备什么。”

# AI 秘书背后做的事情
理解时间和目标 → 写进待办 → 找旧项目/资料 → 判断优先级 → 给出下一步

一句话：ChatGPT 像大脑，Memory / 项目上下文像记忆，TickTick / Calendar / Drive / GitHub / 数据平台是外部系统，插件和 MCP 像把它们接起来的手和脚。

02 / 学业

三小时搞定实训：用 Agent 接管一台 Linux 虚机

传统做法是手敲命令 + 踩坑；Agent 的思路是把环境和完成标准交代清楚，让 AI 真正进入终端执行。

场景对比
搜 5 篇博客 → 抄命令 → SSH 配错 → 继续排错
→
开启 SSH → 给 Agent 环境信息 → 用 tmux 保持会话 → AI 自己执行并回读确认

关键不是“让 AI 告诉你命令”，而是让它知道完成标准

用 SSH 连接 VMware 虚拟机，只通过宿主机 ssh + 虚机 tmux 工作。
先检查共享会话；不存在就创建。
后续操作都发到 tmux。
执行完成后回读 pane，确认目标真的完成。
不要做无关环境探测。
03 / 期末

一晚上搞定期末复习：让 AI 帮你出题 + 解析

把老师 PPT、教材或笔记喂给 AI，先抽高频考点，再按章节出题、做题、批改、讲错题。重点不是“让 AI 替你考试”，而是把复习反馈速度拉起来。

06 / 写码技巧

AI 写代码的一些技巧

  • 先给上下文，再给任务：报错、关键代码、目标输出，比一句“帮我修一下”有效得多。
  • 明确完成标准：让 AI 跑测试、回读结果，不靠“应该好了”。
  • 把大任务拆成可验证的小步：一处一改、一轮一测，出错更容易定位。
  • 善用 Git：AI 写得越快，越需要版本控制兜底。
  • 让 AI 解释为什么：你不需要手敲所有代码，但至少要能判断它做得对不对。
